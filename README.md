## ⚙ Installation

Clone the repository

```bash
git clone https://github.com/Vishvamoorthi/PORTFOLIO.git
```

Navigate to project

```bash
cd PORTFOLIO
```

Install dependencies

```bash
npm install
```

Run locally

```bash
npm run dev
```

Build project

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
